Add a Global Search feature in the dashboard top bar.

IMPORTANT
- Frontend only for now
- Mock data only
- Design it so it can later connect to the backend
- Must be reusable and scalable

PURPOSE

The search should work across the entire dashboard, not just the current page.

The user should be able to quickly find:

- Clients
- Cars
- Rentals
- Booking Requests
- Locations
- Maintenance Records

TOP BAR

Add a search input in the center or left side of the top bar.

Placeholder:

"Search clients, cars, rentals..."

Design:
- Rounded full-width input
- Search icon on the left
- Clear button on the right when typing
- Premium light style
- Same design language as the rest of the dashboard

DESKTOP

Width:
- 350px to 500px

MOBILE

Collapsed search icon
Tap to expand search

- Focus search automatically
- Dark overlay behind
- Command palette style modal

- Linear
- Raycast
- Notion
- Vercel Dashboard

Design:
- Centered modal
- Rounded corners
- White background

- Search field at top
