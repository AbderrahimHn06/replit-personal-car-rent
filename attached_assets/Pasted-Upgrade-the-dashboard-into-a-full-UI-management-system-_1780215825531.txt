- Walk-in / offline customers

- Returns
- Cars

- Availability
- Maintenance

- Urgent alerts panel

4. Rentals Management
- Full rentals table
- Fields: rental reference, client, car, start date, end date, total price, deposit, status
- Status badges: active, overdue, completed, reserved
- Actions: view details, mark returned, extend, print agreement
- Rental details side panel or modal

5. Cars / Fleet Management
- Grid or table view of cars
- Fields: image, brand, model, year, plate, daily price, transmission, fuel, status
- Status badges: available, reserved, rented, maintenance
- Filters by status, type, transmission
- Add/edit car modal UI
- Car details panel with rental history, mileage, notes, maintenance info

6. Clients
- Client table
- Fields: name, phone, whatsapp, city, total rentals, status
- Separate tabs for online clients and walk-in clients
- Client profile modal
- Actions: view, edit, create rental, block client

7. Blocked Clients

- Reason, date blocked, related rentals

8. Availability

9. Maintenance

10. Alerts / Notifications

11. Reports / Summary
