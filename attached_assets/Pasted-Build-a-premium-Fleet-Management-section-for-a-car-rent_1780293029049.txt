Build a premium Fleet Management section for a car rental agency.

IMPORTANT
- Frontend only
- Mock data only
- No backend
- No API logic
- No real business logic
- Luxury light theme
- Highly readable
- Spacious layout
- Custom UI, not a generic admin template

PAGE PURPOSE

The Fleet page is the central place where the agency manages vehicles.

The user must be able to:
- View all cars
- Check availability
- Check status
- Open detailed vehicle profiles
- Add vehicles
- Edit vehicles
- See maintenance information
- See rental history
- Access vehicle schedule

The page should feel like a modern fleet command center.
