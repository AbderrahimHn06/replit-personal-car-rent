Unify all client actions with reusable modals and improve the Add Client form.

IMPORTANT
- Frontend only
- Mock data only
- No backend
- No API calls
- No real persistence
- Use local state only
- Keep the UI premium, clean, and consistent with the rest of the dashboard

1) REUSE THE SAME RENTAL MODAL FROM CLIENT PROFILE

Inside the client profile, the button “Create Rent” must open the exact same rental creation modal used everywhere else in the app.

Do not create a separate rent form for the client profile.

Use one shared component:
RentalCreationModal

It must work from:
- Availability → Book
- Rentals → New Walk-in Rental
- Client profile → Create Rent

When opened from a client profile:
- the selected client must be prefilled automatically
- the user should not select the client again
- the same premium modal layout must be reused
- only the client context changes

2) REUSE THE SAME CLIENT MODAL FOR EDIT AND CREATE

The client profile actions should use one shared client form modal:

ClientFormModal

Use it for:
- Add Client
- Edit Client

When opened in Add mode:
- empty form

When opened in Edit mode:
- prefilled form

Do not create separate add/edit forms.

3) CLIENT PROFILE ACTIONS TO FUNCTIONALIZE

From the client profile, these buttons must work using real UI behavior with local state:

- Create Rent → opens RentalCreationModal prefilled with this client
- Edit Client → opens ClientFormModal in edit mode
- Block / Unblock → opens confirmation modal
- Add Note → opens note modal

All of them should feel connected and consistent.

4) BLOCK / UNBLOCK MODAL

Block modal content:
- Client name
- Reason textarea
- Optional note
- Confirm button
- Cancel button

Unblock modal:
- Show previous block reason
- Confirm unblock button
- Cancel button

This should update local state only.

5) ADD NOTE MODAL

Add a clean note modal for client profile.

Fields:
- Note title
- Note content
- Priority if needed
- Save / Cancel

Saved notes should appear in the client profile notes section.
