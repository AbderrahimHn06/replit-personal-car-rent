Fix interaction quality and page behavior across the dashboard without redesigning the UI.

IMPORTANT
- Frontend only
- Mock data only
- No backend

- Use local state only
- Keep the current design system and layout
- Do not redesign the UI, only fix behavior, cursor states, animations, and filtering

1) CURSOR POINTER
A major problem is that many interactive elements do not show cursor-pointer.

Add cursor-pointer to all clickable elements, especially:
- primary buttons
- secondary buttons
- icon buttons
- filter pills
- tabs
- cards that open drawers/modals
- table rows that open details
- search results
- navigation items
- modal close buttons
- action links
- dropdown triggers
- booking / confirm / edit / delete / add buttons

If something is clickable, it must visibly feel clickable.

2) MODAL / DRAWER ANIMATIONS
All modals and drawers must have the same smooth premium animation system.

Apply animation to all of these:
- Add Vehicle modal
- Edit Vehicle modal
- Add Client modal
- Edit Client modal
- Add Note modal
- Block / Unblock Client modal
- Create Rental modal
- New Walk-in Rental modal
- Filters modal or filter panel if any
- Any client details modal or drawer
- Any vehicle details modal or drawer
- Any rental details modal or drawer
- Any confirmation dialog
- Any modal opened from routing actions if present

Animation rules:
- overlay appears with fade in
- modal scales from 95% to 100%
- modal fades in smoothly
- drawer slides from right with fade
- close animation is smooth too
- no abrupt mount/unmount feeling
- no jumpy transitions
- no harsh shadow pop

Overlay:
- fixed inset-0
- bg-black/40 or bg-black/50
- backdrop-blur-sm

Modal style:
- rounded corners
- soft shadow
- centered
- scrollable when content is long
- responsive size
- proper z-index
- close on outside click when appropriate
- close on Escape when appropriate

3) ROUTING TRANSITIONS
Make routing between pages feel smoother.

Apply subtle transition behavior when changing pages:
- slight fade in

- no abrupt content flash
- keep the UI stable while navigating

Do not redesign the routing system.
Just improve the page transition feel and navigation polish.
